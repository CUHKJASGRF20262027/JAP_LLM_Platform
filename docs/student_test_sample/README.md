# 学生答卷格式样例

[返回项目首页](../../README.md) · [上级目录](../README.md)

这里保存两份旧答卷样例，供 Word 答案解析和学生记录导入流程参考。文件名里的数字供旧代码识别学号，不是生成的练习编号。

`insert_db.py` 默认遍历本目录的 `.docx`；`jap_paper_revise.py` 按 `Name:` 段落读取姓名、按 `問題　` 开头的段落和全角冒号读取答案。答题数量和顺序须与标准答案一致，文件名和 Windows 路径格式也受旧解析规则约束。

这些文件不应被直接当作可以自由分发的匿名样例。制作演示副本时，应同步匿名化姓名、学号、文档元数据和相关数据库记录。不要为了查看文件而运行可能删表的导入脚本。
