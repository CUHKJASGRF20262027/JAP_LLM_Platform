# 带教师意见的题目表

[返回项目首页](../../../README.md) · [上级目录](../README.md)

这里保存带教师意见的两份条件表达题目 Excel。文件名中的 `with HO's Comments` 用于区分反馈版本与原始试题。目录名 `4.11shatin` 是历史批次标识，本说明不据此推断具体实验日期或教学成效。

`extract_bad_questions.py` 读取这些文件的 `Suggestions` 列，将 Drop 和 Minor changes 视为需要修改的题，输出对应题号和 0/1 索引。该脚本还保留 OK 标签，其他标签可能被过滤掉。

教师可以用 Excel 阅读题目、选项、答案和修改意见。为维持程序匹配，请在副本上工作，不随意改动原始文件名、前四列顺序和题号。
