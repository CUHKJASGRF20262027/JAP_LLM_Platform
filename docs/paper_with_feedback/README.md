# 教师反馈与词条材料

[返回项目首页](../../README.md) · [上级目录](../README.md)

这里保存教师对题目的意见、程序提取的问题题号，以及用于未来微调数据准备的词条说明。

教师在题目表中表达是否采用和需要修改的内容，程序再把反馈转换成可与模型修订位置比较的索引。反馈不是模型产生的标准答案认证，也不应被改写成已经量化的教学效果。

当前评价标签还不统一，生成表的 High_Q/Low_Q 与提取脚本使用的 OK 等标签并不完全兼容。接入自动统计前，先按出题模块 README 统一标签和题号规则。
