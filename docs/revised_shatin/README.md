# 按模型组织的修订结果

[返回项目首页](../../README.md) · [上级目录](../README.md)

这里按模型名或实验组存放 Excel 修订产物和文本日志。当前提交了一个模型子目录的部分历史样例，并没有完整保留所有模型的实验输出。

运行修订脚本后可能新增其他模型目录、`voting_group_1` 至 `voting_group_4` 或 `model_comparison_summary`。比较汇总目录存的是修改位置统计，不是已证明的题目正确率。

`combine_excel_paper.py` 合并分片时会删除选定目录中的原 Excel，重跑也可能覆盖同名日志。先备份或另设实验目录。此处新输出默认受 `.gitignore` 忽略规则影响。
