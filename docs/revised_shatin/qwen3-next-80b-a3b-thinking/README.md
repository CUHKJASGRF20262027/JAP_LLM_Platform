# 单模型修订历史样例

[返回项目首页](../../../README.md) · [上级目录](../README.md)

目录名标明当时归档使用的模型名称，不代表该模型目前仍可调用，也不构成模型质量排名。

`_iteration_1.xlsx` 表示第一轮修订的中间产物；`_revised_revised.xlsx` 是在原文件名已经含 revised 的基础上再次添加后缀形成的结果名；`_revision_log.txt` 记录修订过程。后缀重复属于脚本命名约定，不自动意味着恰好修订两轮。

最终文件可能在达到最大轮数、没有新的修改或模型没有再报告错误后保存。应结合日志和教师复核判断内容是否可用。当前目录只有部分题目同时保留中间文件与日志，不能假定所有文件都有完整实验链。
