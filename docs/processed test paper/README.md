# 试卷清理中间文件

[返回项目首页](../../README.md) · [上级目录](../README.md)

这里保存 `jap_paper_revise.py` 清理原始 Word 试卷后留下的中间材料，例如移除示例或分隔内容后的文档。

当前文件名含有时间戳，用来区别不同保存版本。这些文件用于排查解析和拆题过程，不是新的学生答卷、模型训练结果或最终学习分析报告。

解析模块末尾存在未被主程序保护的示例调用，导入该模块也可能处理文档并产生文件。阅读代码无需执行此模块，接手开发应先移除这种导入副作用。

## 本目录的每个文件和子目录

| 文件或目录 | 用途 |
| --- | --- |
| `README.md` | 当前目录的阅读说明与逐项索引。 |
| [Test 1 Question Paper 20250909113919.docx](Test%201%20Question%20Paper%2020250909113919.docx) | 清理后带保存时间戳的 Test 1 试卷中间文件，供排查拆题效果。 |

以上清单对应交接时仓库已有材料。运行脚本产生的新文件应按实际用途记录，不能仅凭目录名推断审核状态。
