# 生成初稿样例

[返回项目首页](../../../README.md) · [上级目录](../README.md)

本目录保存生成流程的初稿样例。当前有同一条件表达知识点的 Excel 和 Word 文件，便于分别查看表格形式和排版形式。

这些是后续修订、教师检查或格式比较的起点。初稿中的答案和语言内容仍需人工核对。`config.grammar_output_path` 默认指向这里，但其他版本也可能在文件内自行指定路径。

此目录的新生成文件默认被 `.gitignore` 忽略；已提交的历史样例仍受 Git 跟踪，修改它们仍会出现差异。
