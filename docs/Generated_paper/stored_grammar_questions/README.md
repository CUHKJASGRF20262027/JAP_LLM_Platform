# 旧入库流程的归档样例

[返回项目首页](../../../README.md) · [上级目录](../README.md)

旧 `SQL_Database/Excel2Db.py` 会把扫描处理后的 Excel 从 `revised_grammar_questions/` 移到这里，避免下次仍留在原输入目录。

文件在这里并不能证明当前数据库里存在对应记录，也不能证明它已经通过审核。现有导入脚本的语法题兼容性、标签筛选和成功记录仍需修复。此目录不是数据库备份。

当前保留一个条件表达题目表，主要供交接者理解旧文件流程。新生成归档默认受 `.gitignore` 规则影响。
