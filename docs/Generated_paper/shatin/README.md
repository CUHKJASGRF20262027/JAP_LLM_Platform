# 修订实验的输入题目

[返回项目首页](../../../README.md) · [上级目录](../README.md)

这里是当前多条实验流程的输入目录，存放条件表达相关题目的 Excel。

`jap_question_generator_v3_1_qwen_based.py` 直接读取这里的整份题目，`split_excel_paper.py` 从这里切分小批次，`v3_2` 将这里的原题与模型修订题比较。为保持对比关系，原题文件应保留不动，用单独目录存放新实验。

文件名中的语法词条用于识别题目批次。重命名会影响修订文件和教师反馈文件的匹配，改名前应同步检查所有关联输入。
